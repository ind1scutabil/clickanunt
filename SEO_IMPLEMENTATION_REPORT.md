## 2. What was optimized / changed

- **`app/sitemap.ts`:** Now **static/marketing URLs only** (no 50k inline listing URLs). Listings moved to scalable shards.
- **`app/head.tsx`:** Returns `null` to avoid duplicating global JSON-LD (legacy file).
- **`app/robots.txt` / `app/sitemap.xml`:** Still generated by Next conventions; robots references all sitemap endpoints.
- **OpenGraph:** `createPageMetadata` maps unsupported `product` OpenGraph type to **`website`** (Next type limitation).
- **Images (LCP hint):** Listing grid already uses `loading="lazy"` after the first three cards — unchanged behavior, noted for CWV.

## 3. Sitemap URLs (production)

Assume `NEXT_PUBLIC_SITE_URL=https://www.clickanunt.ro` (no trailing slash).

| URL | Role |
|-----|------|
| `https://www.clickanunt.ro/sitemap.xml` | Core static pages (`/`, `/listings`, legal, business, security). |
| `https://www.clickanunt.ro/sitemap-categories.xml` | **Rewrites** → `/sitemap-serve/categories` — all valid `/{categorySlug}/{citySlug}` pairs from `MARKETPLACE_SEO_CITIES`. |
| `https://www.clickanunt.ro/sitemap-cities.xml` | **Rewrites** → `/sitemap-serve/cities` — `/auto/{citySlug}` hub for every city in the SEO city list. |
| `https://www.clickanunt.ro/sitemap-listings.xml` | **Rewrites** → `/sitemap-serve/listings-index` — sitemap **index** for listing shards. |
| `https://www.clickanunt.ro/sitemap-listings-0.xml` | **Rewrites** → `/sitemap-serve/listings/0` — up to **45 000** listing URLs per shard (`LISTING_SITEMAP_CHUNK_SIZE`). |

**Scale note:** Shards use `skip` pagination. For **very large** offsets this can become slow; a future improvement is **keyset / cursor-based** chunking or offline generation to object storage (documented in audit).

## 4. New public routes (examples)

- **Programmatic hubs:** `/{canonicalCategorySlug}/{citySlug}`  
  Examples: `/imobiliare/timisoara`, `/locuri-de-munca/iasi`, `/electronice/bucuresti`  
  Aliases: `/telefoane/cluj-napoca` resolves content for electronice; **canonical** in metadata points to `/electronice/cluj-napoca`.

**Reserved slugs** (404 as market page): `about`, `listings`, `admin`, `api`, `auth`, `dashboard`, etc. — see `RESERVED_CATEGORY_SLUGS` in `lib/seo/market-paths.ts`.

## 6. “SEO score” / metrics

No automated Lighthouse or Search Console score is claimed here (needs live URL + key + time). Expected qualitative gains:

- Richer titles/descriptions on **home**, **browse**, **listing**, **city/category** landings.
- Better crawl coverage via **sitemap index + shards** and **internal hub URLs**.
- Eligible rich results: **Product**, **BreadcrumbList**, **Organization**, **WebSite** + **SearchAction**, **CollectionPage** on hubs.

## 7. Remaining recommendations

1. **Keyset sitemap generation** at extreme scale (avoid `OFFSET` for high chunk indices).  
2. **ISR / revalidate** for hub pages if DB load becomes visible (currently dynamic per request).  
3. **Review global `Cache-Control`** on `/:path*` in `next.config.ts` — may cache HTML aggressively; adjust per-route if freshness issues appear.  
4. **Subcategory segments** (third path segment) if product needs deeper landings.  
5. **Hreflang** only if multi-language ships.

## 9. Safe production deploy (commands)

On your machine (commit + push), then on the VPS (same pattern as existing `deploy:prod` script):

```bash
# Local
git add -A
git status
git commit -m "feat(seo): metadata, structured data, sitemaps, category/city hubs"
git push origin messaging-stable   # or your production branch

# VPS
ssh root@46.225.69.155
cd /var/www/clickanunt
git pull origin messaging-stable   # or your branch
npm ci
NODE_ENV=production npm run build
npx prisma migrate deploy            # no schema change expected; safe no-op
pm2 reload ecosystem.config.js --update-env
pm2 save
```

**Post-deploy checks**

1. `curl -sI https://www.clickanunt.ro/robots.txt | head`  
2. `curl -s https://www.clickanunt.ro/sitemap.xml | head`  
3. `curl -s https://www.clickanunt.ro/sitemap-listings.xml | head`  
4. Open `/auto/bucuresti` and view source — confirm `<title>` + JSON-LD.  
5. Search Console → Sitemaps → submit the four sitemap URLs + parent `sitemap.xml`.
